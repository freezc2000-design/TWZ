## 开始游戏

1. 下载 `TWZ-Windows-0.3.8-20261006.1.zip` 并完整解压。
2. 双击 `TWZ.exe` 启动，使用游戏内登录界面进入游戏。
3. 保留 `TWZ.exe` 与 `TWZ_Data` 等运行文件的原有目录关系。

技能键为 **1–7**，**空格**冲刺，**F**拾取或使用传送门。

本次为客户端修复包，与云端 **0.3.8（20261005.2）** 使用相同网络协议，已实测兼容。两端构建号不同属于预期。

请下载 Release 中的客户端附件；GitHub 自动提供的 **Source code** 压缩包仅含本仓库的说明文件，不是游戏客户端。

本仓库用于客户端分发。测试服务运行在云端，无需在玩家电脑上启动服务端。更新客户端保留原有本机账号身份和云端存档。
