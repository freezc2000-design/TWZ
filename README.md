# TWZ

Windows 联网 RPG 测试客户端。

## 下载

- [下载最新 Windows 客户端](https://github.com/freezc2000-design/TWZ/releases/latest/download/TWZ-Windows-0.3.8-20261003.6.zip)
- [查看版本与更新说明](https://github.com/freezc2000-design/TWZ/releases/latest)

当前版本：**0.3.8（20261003.6）**。客户端与服务器已配套更新。

## 开始游戏

1. 下载 `TWZ-Windows-0.3.8-20261003.6.zip` 并完整解压。
2. 双击 `TWZ.exe` 启动，使用游戏内登录界面进入游戏。
3. 保留 `TWZ.exe` 与 `TWZ_Data` 等运行文件的原有目录关系。

技能键为 **1–7**，**空格**冲刺，**F**拾取或使用传送门。

请下载 Release 中的客户端附件；GitHub 自动提供的 **Source code** 压缩包仅含本仓库的说明文件，不是游戏客户端。

本仓库用于客户端分发。测试服务运行在云端，无需在玩家电脑上启动服务端。

## 校验

Release 附件中的 `SHA256SUMS.txt` 提供安装包 SHA-256 校验值。
